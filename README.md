## Projetos

**[onBoard](https://github.com/lipefp/onBoard)** — Inventário de equipamentos de rede. Django REST Framework + React (Vite) + MySQL, autenticação JWT e UI em Tailwind.

**[taskflow](https://github.com/lipefp/taskflow)** — API REST em Django REST Framework com autenticação por token, regras de transição de status e paginação.

**[workshop-manager](https://github.com/lipefp/workshop-manager)** — Sistema desktop em PyQt5 para oficinas: ordens de serviço, financeiro e emissão de PDF com ReportLab.

**[autoflux](https://github.com/lipefp/autoflux)** — Marketplace mobile de autopeças em React Native (Expo + TypeScript) com back-end em Django REST Framework.

**[caixa-pessoal](https://github.com/lipefp/caixa-pessoal)** — Livro-caixa pessoal em HTML/JS com Supabase (Postgres + RLS), hospedado no GitHub Pages.
